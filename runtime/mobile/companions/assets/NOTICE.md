# Companion assets

- `kaka.png`: Droy's legacy black-cat avatar, retained for existing image references.
- `maimai.png`: the legacy MaiBot role illustration from [Mai-with-u/MaiBot at fe88ec6b](https://github.com/Mai-with-u/MaiBot/blob/fe88ec6b6053e40eaf430cb5ba7ed7e805add2cb/depends-data/maimai-v2.png), retained for existing image references. See upstream for licensing and attribution.
- `kaka-v2.png`: AI-generated human office-worker portrait selected for Kaka. The black-haired, amber-eyed male design replaces the black-cat companion identity; the separate animated pet is unchanged.
- `maimai-v2.png`: AI-generated square portrait adapted from the MaiBot role illustration above, retaining its orange hair, beret and clover motifs. The original role and illustration attribution remain with MaiBot and its contributors.
- `dafeiyu.png`: AI-generated square portrait adapted from the community whale-girl design: original character by 上善无形, DeepSeek maid adaptation by ZipZipPipe, and the Q-version reference by [YunYueSama](https://github.com/YunYueSama/codex-deepseek-pet/blob/main/design/character-standard.png). The reference project lists CC BY-NC-SA 4.0; retain the attribution, non-commercial and share-alike terms for this derived character artwork. This is a community character, not an official DeepSeek asset.
- `claude.png`: AI-generated square portrait adapted from ZipZipPipe's community Claude character, using the [AI Moe Atlas collection](https://selinlee.github.io/ai-moe-atlas/zh/assets/) of the [original illustration](https://www.pixiv.net/artworks/148186519). The collection specifies attribution and non-commercial use according to the author's statement. These character-art terms are separate from the repository's source-code license; no official Anthropic affiliation is implied.
- `test-sticker-*.png`: generated temporary test stickers, intended to be replaced with the product's sticker collection.
- `sticker-support`, `sticker-rest`, `sticker-surprised`, `sticker-sad`, `sticker-wave`, and `sticker-thinking`: original Droy vector artwork, distributed under this repository's AGPL-3.0-only license. Editable SVG sources are in `source/`; run `node tools/render_companion_stickers.mjs` from the repository root to reproduce the native PNG assets using the installed runtime's Sharp dependency. No third-party artwork or fonts are used.

- `wallpaper-01` through `wallpaper-08`: Droy chat backgrounds created with OpenAI image generation and distributed under this repository's AGPL-3.0-only license. The full images are 841×1870 lossless WebP files; thumbnails are 180×400 WebP files. No upscaling is applied. They replace the former geometric backgrounds.

| IDs | Style | Variants |

| `01`, `02` | Fine paper texture | Light, dark |
| `03`, `04` | Soft mist gradient | Light, dark |
| `05`, `06` | Leaf shadows on plaster | Light, dark |
| `07`, `08` | Sparse hand-drawn line art | Light, dark |
