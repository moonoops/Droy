# MaiBot Chinese typo adaptation

`../maibot-typo.mjs` ports MaiBot's `ChineseTypoGenerator` and correction-bubble
postprocessor at commit `fe88ec6b6053e40eaf430cb5ba7ed7e805add2cb`. The original
sources and GPL-3.0 notice are included in `upstream/` and `LICENSE.MaiBot`.
The default probabilities, frequency thresholds, tone substitutions, whole-word
selection, correction suggestion and quoted-correction decisions are preserved.

The Android runtime uses JavaScript. `lexicon.json.gz` contains the complete
jieba 0.42.1 word-frequency dictionary and HMM model, and pypinyin 0.55.0 character
and phrase pronunciations. These are the versions in MaiBot's pinned `uv.lock`.
Their MIT notices are `LICENSE.jieba` and `LICENSE.pypinyin`. No Python service,
Root permission, external dictionary download or model call is required at run
time. The data is loaded once, only for Chinese casual replies.

The word-homophone index stores sorted 32-bit hashes and dictionary positions.
Lookup checks the complete pronunciation sequence after the hash match. This
retains the same candidate set and Unicode tie order as upstream's Cartesian
product followed by dictionary filtering, without expanding impossible words.
Word-frequency lookup uses a sorted array, avoiding hundreds of thousands of
JavaScript objects on mobile.

Host adaptations preserve work results, structured lists/tables/code, URLs,
identifiers and explicitly protected names. English replies do not receive
Chinese typo processing. These exemptions protect content the user will copy
or execute; casual Chinese still uses the upstream mechanism. The input is
split into sentences first, typo/correction processing runs second, and the
caller merges ordinary bubbles last while retaining correction boundaries.

To regenerate with Python 3.11 or later:

```sh
python -m pip install jieba==0.42.1 pypinyin==0.55.0
python -B runtime/mobile/companions/maibot-typo-data/generate.py
python -B runtime/mobile/companions/maibot-typo-data/reference_cases.py
node --test runtime/mobile/tests/companion-maibot-typo.test.mjs
```

`provenance.json` records the source and generated hashes. The reference cases
are generated by the unchanged upstream class and postprocessing function,
with an identical random-number stream for the Python and JavaScript runs.
They cover segmentation, contextual pronunciations, homophone selection and
visible correction metadata. The data generator does not run on installation.
