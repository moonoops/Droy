# 创建或编辑 Droy 技能

仅在用户要求保存做法、创建或修改技能时使用。普通手机任务直接执行，不在任务结束、失败或空闲时自行创建技能。

1. 调用 `android_capabilities`，取得 `droySkillsDirectory`。使用现有文件工具查看该目录中的 `<技能名>/SKILL.md`；不修改随包内置技能，也不写入 DSH 安装目录。
2. 查看已有个人技能。相同目标优先更新现有文件，编辑前读取当前内容；不同商品、时间、预算和对象作为参数，不分别新建技能。
3. 提炼用户要求保留的步骤、适用条件和完成依据。正文保持简短，不积累执行日志、聊天记录和一次性页面坐标。
4. 文件使用 YAML frontmatter，包含小写连字符形式的 `name` 和简短、明确的 `description`。正文说明仅用于 Droy Android，调用当前可用的 Android Use／Droy 工具；执行后端由 Droy 选择，不要求 Root 或 Shizuku，不引用 DSH 内部包、运行路径或版本。普通用户偏好和一次性任务参数不需要单独成为技能。
5. 调用 `droy_skill_save`，传入技能名与完整文件内容。保存后用文件工具读回，确认内容并简短说明创建或更新了哪个技能。只有实际复测了业务流程，才说明它已复测通过。

技能保存可复用的方法，不保存账号凭据或把一次成功扩大为所有应用版本通用的规则。创建技能的要求不授权额外购买、发送或修改手机设置。
