# README artwork / README 展示素材

These assets accompany Droy v0.0.3. Screens are actual app captures rather
than generated UI.

这些素材用于 v0.0.3 的 README。屏幕内容来自实际应用截图，未由图像模型重绘。

## Screens / 界面

- `screenshots/chat.*.png`, `tasks.*.png`, `companions.*.png`, and `background.*.png`: native UI on an isolated Android 16 / API 36 ARM64 emulator, using Droy Dev v0.0.3, version code 8. APK SHA-256: `7c5f880a31c5b2f3cad4545dbe7c22de47ecfb7612df7c3d1e10c186454c2d70`.
- Conversation text, profiles added to the list, and the hiking checklist are fictional demonstration data. The checklist is rendered by the actual Tasks interface using a local fixture provider. These images are not evidence of a cloud-model response or phone-operation execution.
- The four preset names and avatars are the shipped defaults. A fresh installation starts with Kaka only; the other three were added for the showcase.
- `screenshots/pet.*.png`: native v0.0.3 pet settings, captured during release checks on an Android 16 / API 36 ARM64 emulator.
- Phone frames, lighting, headings and layout are rendered in HTML/CSS. No claim of a particular physical phone model is intended. Raw screenshots retain their original text and layout.

聊天、列表及任务使用虚构演示数据，没有调用真实云模型，也不代表一次手机操作验证。四套预设来自应用自带资源；新安装仍只创建咔咔。手机机身为渲染外框，不对应特定真机型号。

## Brand illustration / 品牌插画

`brand-cat.png` was generated with the built-in image generation tool, using
the project's `app/src/main/assets/pet/reference.png` as an identity reference.
This is promotional artwork for the black-cat pet/brand, not a screenshot or
the Kaka companion avatar. The in-app pet remains pixel art.

黑猫是宠物/品牌宣传插画，不是咔咔聊天伙伴的头像；应用内宠物仍为像素画。
