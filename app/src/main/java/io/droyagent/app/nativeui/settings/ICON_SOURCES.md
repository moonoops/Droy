# Settings icons

The `native_settings_*.xml` drawables preserve Google Material Symbols Rounded
path geometry under Apache 2.0. Each source is:

`https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsrounded/{name}/default/24px.svg`

Names: settings, language, hub, person, arrow_back, add, chevron_right.

The review update adds `tune`, `neurology`, `auto_stories`, `travel_explore`,
`notifications`, `filter_list`, `pets`, and `info` at optical size 24, weight
400 and grade 0, from Google's repository:

`https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/{name}/materialsymbolsrounded/{name}_24px.svg`

Their geometry is preserved; the vector group translates the SVG viewBox origin.
The Apache 2.0 license is included in `assets/licenses/material-symbols/`.
