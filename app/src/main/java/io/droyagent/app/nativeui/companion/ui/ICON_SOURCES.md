# Companion icons

The `native_companion_*.xml` drawables preserve the original Google Material
Symbols Rounded path geometry and use the Apache 2.0 license. The source URL
for each filename suffix is:

`https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsrounded/{name}/default/24px.svg`

Icons: arrow_back, more_vert, reply, delete, attach_file, mic, play_arrow,
person, push_pin, image, sentiment_satisfied, chevron_right.

The Android vectors translate the source view box's y origin by 960 and take
their display color from the shared Material theme.
